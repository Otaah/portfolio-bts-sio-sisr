# Preuves du projet

Aucune preuve n'est encore fournie. Les noms suivants sont proposés pour les
fichiers à créer à partir des essais réels.

| Nom proposé | Contenu |
| --- | --- |
| `01-ssh.png` ou `01-ssh.txt` | Valeurs effectives et connexion par clé, sans exposer la clé. |
| `02-pare-feu.png` ou `02-pare-feu.txt` | Règles et tests depuis le client et le PC avant/après. |
| `03-journaux.png` ou `03-journaux.txt` | Courts extraits commentés liés aux essais. |

Une capture lisible ou un extrait texte suffit pour chaque point important.
Conserver la commande et la sortie utile. Les tests complets restent décrits
dans `../validation.md`.

Pour chaque preuve, ajouter cette légende avec les valeurs observées :

> Date : [date]. Machine : [nom]. Action : [commande ou manipulation].
> Observation : [résultat réel]. Conclusion : [ce que cela démontre].

Après ajout d'un fichier, créer son lien relatif dans la colonne « Preuve » du
tableau de validation. Ne pas ajouter de lien vers une capture qui n'existe pas.
Relire le contenu pour exclure mots de passe, clés privées et informations
personnelles étrangères au laboratoire.
